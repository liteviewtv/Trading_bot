# Free Trading Bot

A modular, paper-trading-first automated trading system.

## Phase 1

This project starts with a safe paper-trading foundation. No live orders are enabled.

### Planned stack

- Python
- Alpaca Paper Trading API
- SQLite
- Telegram notifications
- Configurable strategy and risk engine
- Backtesting before any live deployment

## Safety

Live trading is intentionally disabled in the initial implementation. API credentials must be supplied through environment variables and must never be committed to Git.
